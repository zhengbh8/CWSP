\chapter{绪论}

\section{研究背景与意义}

最优化路径规划问题（Shortest Path Problem, SPP）是运筹学、计算机科学与交通工程领域最为经典且核心的基础研究课题之一。自 20 世纪 50 年代以来，以 Dijkstra 算法\cite{dijkstra1959note}为代表的经典最短路径求解策略奠定了图论寻优的基础框架。传统的最短路径算法在网络拓扑固定且边权值相互独立（即满足加性原理：连续几段边路径的总代价值严格等于各边代价之和）的假设条件下，能够高效且精确地寻找到两点之间的最优可行策略。这种基于“贝尔曼最优化原理（Bellman's Principle of Optimality）”的贪心延展策略，长久以来被广泛应用于数据路由分发、电子地图导航和供应链物流规划中。

然而，随着现代交通网络复杂度的剧增、自动驾驶集群的规模化演进以及无人机蜂群的三维空间避障需求的提高，传统加性最短路径模型的应用局限性被急剧放大。在以上诸多真实的物理工程场景中，路径的通行代价往往不仅仅取决于单条物理路段本身的静态属性（如路的长度或限制速度），更取决于车辆或载体在路段之间穿梭时的连贯动态行为。例如，在自动驾驶车辆跨越城市复杂交叉路口时，“左转”、“右转”或“掉头”这三种不同的运动轨迹，会受到信号灯相位、交通流阻力甚至车辆本身物理转弯半径的制约，从而产生截然不同的行驶时间与能源消耗跳变。在这种状态下，由几条路段所组合成的实际通行代价，将远远大于或不等于这些路段孤立存在时的代价总和——这种由于两条相邻边形成的拓扑夹角及物理特性带来的连续影响被称之为“非加性约束（Non-additive Constraints）”。

传统的 Dijkstra 或 A* 等贪心算法默认子路径的局部极小性等价于全局极小性，因此彻底失去了对前驱历史状态的记忆与感知判断。倘若直接强行在算法搜索中添加动态约束校验，极易陷入局部死锁甚至在极端转角惩罚下导致算法无法收敛、直接崩溃。为了从理论上彻底解决基于上下文记忆的连续约束规避问题，将原图网络（Graph）通过拓扑投影转换为“线图（Line Graph）”以构建附带条件权重的最短路径模型（Conditional Weighting Shortest Path, CWSP）成为了一种极具潜力的架构设计。它将原网络中的原边转化为新网络的定点，并将相邻两条原边之间的非加性关联映射成为新网络中的边权。在这一高阶空间中，复杂的历史依赖被内化吸收为新节点的静态特征，使之完美契合经典的单源寻路理论。

尽管线图映射极大提升了寻路的理论精度并满足了绝对安全的非加性避障约束，但这套机制会引发网络规模的灾难性爆炸：伴随边（线图边集）的数量呈现 $O(m^2)$ 态势陡增。当图网规模达到百万或千万级别时，仅依靠目前传统的中央处理器（CPU）进行串行的图映射拼接与随后的路径松弛计算，其计算时延往往会攀升至数秒甚至数分钟以上，这对于毫秒级响应的实时智驾调度与大规模微观交通流模拟而言是绝对不可接受的。

因此，在这一背景下，如何通过深入挖掘并发硬件潜力，打破因拓扑膨胀带来的算力瓶颈具有极大的学术挑战与工程价值。现代图形处理器（Graphics Processing Unit, GPU）所具备的数以万计的逻辑线程以及极高吞吐的显存带宽，为突破这一算力死锁提供了理想的架构级支撑。基于此，本文旨在针对非加性约束引出的巨型网格，从底层构建完全无锁的 GPU 并发结构，并通过改造 SIMT（单指令多线程）调度流水线以及适配高延展度的 $\Delta$-Stepping 寻优松弛算法，全面彻底地扫清算法全链路的串行障碍。

本文研究的意义主要体现在以下两个方面：
第一，在理论模型层面，揭示并梳理了大规模图数据从低阶映射到高阶线图空间中的内在依赖冲突，使得原本不可求解或极度耗时的多属性非加性代价模型得以被系统性结构化表达。
第二，在工程应用层面，通过提出的 GPU 并行前缀和拓扑重构、并发谓词权值对齐及并行的松弛桶队列管理等核心技术，将原先高达上百秒的计算时延直接压缩至几百毫秒级别的实时标准内。实现了近百倍的理论加速比，这为智能交通枢纽调度及超大型密集运算提供了极具可落地的工业级高时效求解方案。


\section{国内外研究现状}

\subsection{传统最短路径算法及非加性特征变体}

自 20 世纪下半叶图论获得系统性突破以来，最短路径问题经过充分发掘，涌现了众多成熟的基础算法。Dijkstra\cite{dijkstra1959note} 最早提出了优先队列式迭代拓展的单源最短路径松弛法。由于该算法基于极其严谨的安全判定，其理论下界表现极为优秀。随着研究的深入，学术界逐渐将重点向受到复杂干扰的随机网络及多维属性约束系统上偏移。Loui 首先在带随机分布路权的场景下对最优化路径进行了讨论，提出必须将多维约束与方差结合考量\cite{loui1983optimal}。此后，Henig 对双目标或多标靶环境下的最佳路线模型进行了深度的启发式裁剪\cite{henig1986shortest}。

针对更贴合实际路况的“非加性问题”，特别是带有极其严苛的物理转弯阻抗与节点过渡代偿的条件带权图，早期的学者大多采用修改顶点标签（Label-correcting）来勉强维持传统算法。Winter 在大型交通路网的转弯禁行系统中，使用了扩展标签的方式强行让 Dijkstra 算法绕过不可行解\cite{winter2002labeling}，但这使得空间复杂度不可控。Nikolova 等人讨论了在面对具有方差限定与非相互独立路权的非加性体系下的多项式逼近问题\cite{nikoletta2010variance}，Sen 等人则在先进旅人信息系统中为应对路线引导，设计了通过均值-方差过滤的最优动态决策树\cite{sen2001mean}。近年来，为了克服由于缺乏上下文而无法预测代偿惩罚的难题，Murphy 等人提出了一种新型非加性条件下条件带权图框架，旨在彻底规范化机器人在受物理学与地形制约时的路径预测行为\cite{murphy2018generalized}。对于具有二次特性的最短路问题（QSPP），由于其具备极强的组合相关约束及 NP 完全属性，Rostami 等与 Hu 团队通过线性重构及多项式分级化简给出了进一步的收敛理论推演\cite{rostami2015solving, hu2017polynomial}，亦验证了纯启发或原生算法在这类非互斥系统下极低的收敛表现。在此类背景下，学界迫切需要寻找一种可以在底层逻辑上化解组合约束的数学模型体系。

\subsection{线图理论及空间高阶拓扑映射}

早在 1932 年，数学家 Whitney 就首次揭示并探索了线图（Line Graph 或称为 Interchange Graph）的同构性质及其内在连通度\cite{whitney1932congruent}。线图的结构是将有向图或无向图中的边和节点互换构建关联矩阵。随后，Harary 等人详细归纳了有向线图（Line Digraph）的传递闭包规律与度数守恒分配等深层性质\cite{harary1960some}。Melter 也对有限网络中的线图置换群理论给出了深入推引\cite{melter1962interchange}。由于早年间计算资源的紧缺，线图高昂的空间裂变倍数（往往可达数倍至数百倍扩张）限制了其在工程界的直接计算利用。

然而，随着图神经网络（GNN）的兴起与非加性问题重整化需求，大批学者重新拾起了线图这一“降维打击”利器。Grandoni 和 Müller-Hannemann 在探讨多级边成本的重估方案中，指出通过转移与重构邻接状态不仅能让多种关联计算化繁为简，甚至能够直接消除因预估误差导致的寻路死锁环\cite{grandoni2008generalization}。当网络模型升级为线图后，复杂的前后桥连过渡行为就被实体化为一个清晰具体的节点对象。由于此时权重计算不再牵涉前驱与后继之间的状态耦合（已内嵌至伴随边之中），原先带有重度记忆属性的寻路问题，在线图这一高阶展开面上被完美化约成了经典的、各分支剥离独立的马尔可夫决策问题。这也正是本研究所选取的处理所有转角惩罚和交叉约束的核心手段。

\subsection{基于 GPU 的大规模图论并行算法研究}

传统的由于拓扑展开带来的算力海啸往往让串行 CPU 处理方式面临 $O(|V| \log |V| + |E|^2)$ 的时间崩溃。在迈向数百万节点的城际路网推演时，迫切需要引入高度并行的加速引擎架构。随着 NVIDIA CUDA 并行生态规范的普及，基于 GPU 高速缓存与海量并发执行管线的图算法优化开始蓬勃发展。

然而，对于最短路径及其演化算法而言，并发设计面临前所未有的阻抗：Dijkstra 算法基于严格全序管理的优先队列（Priority Queue），这种纯粹的数据强制前后依赖关系天然排斥并发操作（在多线程提取根节点时会引发极端的死锁排队和读写数据碰撞）。为了打开并行切入点，学界引入了 Meyer 等人提出的 $\Delta$-Stepping 算法\footnote{MEYER U, SANDERS P. $\Delta$-stepping: a parallelizable shortest path algorithm[J]. Journal of Algorithms, 2003, 49(1): 114-152.}。该算法通过设置距离跨度为 $\Delta$ 的一系列分级“操作桶（Buckets）”，将相近层级的未访问波前前沿全部容纳进同一平行计算域。桶内节点并发向外松弛，通过原子指令更新，从而在收敛可控与大规模流处理吞吐量之间达到了最平衡的状态。当前最新的研究聚焦在如何避免图网络拓扑映射时的显存随机跳跃读取、降低分支分歧（Divergence）引发的 SIMT 寄存器利用率骤降，以及精准锚定 $\Delta$ 敏感阈值的自动调参等方面。这也是本文开展底层并行架构优化的主要研究与发力靶点。

\section{主要研究内容}

鉴于现代交通网络中受到物理急转弯、路口信号相依等导致的非加性惩罚严重掣肘了传统搜索算法求得最终最佳合法路径的可行性，而直接采用线图进行逻辑降维却又会引爆惊人的算力资源危机。本文提出了一种面向大规模非加性重构的高效并行的条件网络最短路径推演架构（CWSP），其主要研究内容及贡献包括三大部分：
第一部分：基于线图理论的非加性最短路径问题建模与 CWSP 算法框架设计。深入剖析非加性约束条件引起算法回溯及解空间发散的核心根源。利用图论空间映射原理，详细建立由底向上的原图 $G(V,E)$ 至线图 $L(G)$ 的标准化拓扑转换流程，并提出条件带权最短路径（CWSP）算法。明确论证了原网络中的边界向线图节点过渡的邻接点多重语义机制，构建出适应动态转角约束的惩罚权值分配模型，从理论上成功规避由分支夹角引起的连贯通行障碍。

第二部分：跨越算力瓶颈的 CWSP 算法 GPU 并行化架构优化。针对线图重构带来的 $O(m^2)$ 规模膨胀与实时寻路时延问题，深入挖掘 CUDA 的细粒度并行潜力，对 CWSP 算法进行了底层结构重塑。在拓扑构建期，引入两阶段前缀和与无锁 CSR 写入模式，消除边裂变期的高频内存开辟碎片；在路径寻优期，以 $\Delta$-Stepping 算法替代传统的优先队列，通过桶式并行迭代与原子归约指令，彻底打破管线中的锁竞争限制，实现了从图预处理到波前松弛寻优的全链路无锁高并发执行。

第三部分：在大规模交通与复杂网络环境下的数值实验与加速应用评估。为验证并行化 CWSP 算法的准确性及其在现实极端场景下的工程有效性，本文在真实的微观机场起降网络平台与自合成的大范围致密环境中执行了体系化的基准测试。借助毫秒级时间剖析，详细探讨了拓扑稠密度、跨步步长（$\Delta$）等核心调优参数对加速曲线的敏感机制，最终通过对比数据明确论证了本文提出的异构求解模型在应对真实非加性调度时的绝对主导性能优势。
\section{论文组织结构}

本文深入探讨如何基于 GPU 并行算力体系，解决面临非加性连贯约束时的网络最优化导航搜索挑战。全篇组织安排如下：

\textbf{第一章 绪论：} 介绍了研究背景与现实中存在非加性特指最短路径问题的提出意义。从传统的最短路径基础、线图解耦转换到 GPU 环境下的并发重绘探索等角度详细整理了相关领域的国内外发展研究历程，最后对全文的核心研究创新要点和论文编排进行概述。

\textbf{第二章 面向非加性约束的网络空间线图重构理论：} 从数学及图论角度拆解经典单源最短路径加性理论在多重动态连结阻抗下的失效原因。系统性提出并确立了对初始带权约束图进行“边节点互换提取”的线图模型改造工序及权值附加方程。

\textbf{第三章 跨越 CPU 算力瓶颈的 GPU 并行计算优化策略：} 重点剖析结构转换到高阶网格导致的爆炸性状态维跃问题。基于 CUDA 的设备异构特点，对线图构建期的内存拓扑映射、向量权重标定以及大规模并发队列松弛提出了前缀和并发 CSR 重配、SIMT 管线内预测优化及基于分层 $\Delta$-Stepping 的桶队列波前扩展等三大重构策略，深度解读算法硬件底层并发流模型。

\textbf{第四章 数值实验与结果分析：} 在真实的微观机场起降网络平台与自合成的大量递阶规模致密交通流环境中执行对比基准跑分。通过量化的毫秒级用时统计反馈及对不同模块的单独切割测算，从解的可行性与端到端高维网络系统综合提速率等方面给出详细透辟的曲线拐点比对与性能成效核验。

\textbf{第五章 总结与展望：} 对当前所做的技术与架构研究工作与结论进行宏观收摄评估，提炼提速及精准规避约束的关键效用，并指出现有并行资源调度的待突破困境，对后期图计算硬件模型与大规模混合动力约束下的网络流优化进行前景预想。

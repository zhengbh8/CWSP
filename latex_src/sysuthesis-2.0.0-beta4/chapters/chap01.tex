\chapter{绪论}

\section{研究背景与意义}

最短路径问题（Shortest Path Problem, SPP）是图论、运筹优化与网络科学中的经典问题，在交通导航、物流调度、通信路由、机器人路径规划等领域具有广泛应用.传统最短路径模型通常建立在“路径总代价等于所经过各边固定权重之和”的加性假设之上.在这一假设下，路径代价满足无后效性与最优子结构性质，因此 Dijkstra、Bellman-Ford、A* 等经典算法能够较高效地完成求解\cite{dijkstra1959note}.

然而，在大量实际网络中，路径代价往往并不满足简单的线性加和结构.以交通路网为例，车辆经过某一路段的实际代价，不仅取决于该路段本身，还可能受到前序路段、转向方式、禁转规则、信号灯相位以及局部交通状态等因素影响.类似地，在机场滑行调度、自动驾驶轨迹规划、多模式运输与复杂工艺流程控制等场景中，当前一步的转移代价也常常依赖于此前若干步的路径历史.此时，路径总代价不再由各边独立权重直接累加得到，而表现为一类具有有限阶历史依赖的非加性最短路径问题.

为了更准确地刻画这类问题，本文关注路径依赖型最短路径问题，即当前一步的转移代价不仅由当前边本身决定，还可能依赖于前序若干步的局部历史状态（例如前驱边、转向状态、模式切换状态或累计转移信息等）.当代价仅依赖前驱边时，可对应交通网络中常见的转向惩罚与禁转规则等情形；当代价依赖更长但仍有限的历史时，则可刻画更一般的有限阶路径依赖结构.该类问题能够覆盖大量真实应用中的“边间过渡代价”建模需求，也是本文后续研究与方法设计的核心对象.

针对这类问题，直接在原图上应用经典最短路径算法通常会遇到根本性困难.其原因在于，当当前扩展代价依赖于路径历史时，最优子结构可能被破坏，单纯以“当前节点”作为状态已不足以刻画后续决策所需的全部信息.为解决这一问题，一种自然的思路是将隐含于路径历史中的局部状态显式展开，从而把原问题重新表述为一个静态图上的加性最短路径问题.线图（Line Graph）及其高阶扩展为此提供了统一而直接的结构化工具\cite{whitney1932congruent,harary1960some}：对于“代价仅依赖前驱边”的典型情形，只需进行一次线图转换，即可将原图中的边映射为线图中的点，并将相邻边之间的过渡关系映射为线图中的边；对于依赖有限条前序边的更一般情形，则可通过构造高阶线图（或等价的多次线图转换）将有限阶历史显式编码为状态节点，从而实现对有限阶路径依赖的结构化建模.

尽管线图转换为路径依赖型最短路径问题提供了统一的结构化建模思路，但其代价也随之而来.随着历史依赖阶数升高，替代图中的状态数与转移关系会快速增长，线图构建、条件权重计算以及后续最短路径求解的时间与空间开销均可能显著上升.特别是在原图本身规模较大、局部连接较密或者历史依赖阶数较高的情况下，线图转换阶段往往成为整个求解流程中的关键瓶颈.因此，若要使这一建模方法具备实际可用性，就不仅需要解决“如何统一表达有限阶路径依赖”的建模问题，也必须进一步解决“如何高效完成高阶状态展开与替代图构建”的工程实现问题.

近年来，GPU 依靠大规模线程并发能力和较高的内存带宽，已成为图计算和稀疏数据处理的重要加速平台.对于线图转换这类涉及大量邻接展开、边对匹配和结构重建的过程，其本质上包含较强的数据并行特征，因此具有较高的 GPU 加速潜力.尤其是在历史依赖阶数升高、图结构膨胀更加显著的条件下，对线图转换阶段进行并行优化，不仅有助于降低构图耗时，也直接关系到该类方法能否扩展到更复杂场景.

基于上述背景，本文围绕路径依赖型最短路径问题，研究如何借助线图及其高阶扩展实现统一建模，并进一步结合 CUDA 并行框架，对线图转换与后续求解过程进行加速.本文的研究意义主要体现在两个方面：
\begin{itemize}
	\item 在理论建模层面，本文从有限阶历史依赖的路径代价结构出发，给出由原图到（高阶）线图的统一状态展开思路，为路径依赖型最短路径问题提供清晰、结构化的表达框架.
	\item 在工程实现层面，针对历史依赖阶数升高引发的图规模膨胀问题，本文探索 GPU 并行在线图构建阶段的加速潜力，为大规模、复杂历史依赖场景下的高效求解提供实现基础.
\end{itemize}


\section{国内外研究现状}

\subsection{传统最短路径算法与非加性最短路径问题研究}

最短路径问题是组合优化与图算法中的基础问题之一，相关研究起步较早，理论体系也相对成熟.Dijkstra 提出的单源最短路径算法为非负权图上的最短路径求解奠定了重要基础\cite{dijkstra1959note}.此后，研究者又围绕不同应用场景与图结构特点，提出了 Bellman-Ford、A*、双向搜索以及多种基于优先队列或层次化结构的改进方法.这些经典算法虽然在搜索策略、数据结构与适用条件上存在差异，但基本都建立在同一前提之上，即路径总代价可以表示为所经过各边静态权重的线性累加，且边权与路径历史无关.

随着应用问题复杂性的提升，经典加性最短路径模型的局限性逐渐显现.在随机网络、多目标优化以及资源约束等场景中，路径代价往往不再由单一静态边权决定.Loui 讨论了带随机或多维权重图中的路径优化问题，指出此类场景中需要同时考虑多个属性或统计特征\cite{loui1983optimal}；Henig 对双目标最短路径问题进行了研究，推动了多属性路径优化方向的发展\cite{henig1986shortest}.这些工作表明，当路径代价受到多维属性、随机性或状态演化影响时，传统最短路径模型需要相应扩展.

在更一般的非加性最短路径问题中，研究者已从多个角度展开讨论.例如，在资源约束型问题中，路径可行性与累计资源状态紧密耦合；在时间依赖型问题中，边权会随出发时间变化；在随机性与相关性问题中，边权可能表现为随机变量并伴随相关结构.与这些类型相比，路径依赖型非加性最短路径问题具有更直接的结构特征：当前扩展代价不仅取决于当前边本身，还可能依赖于此前已经经过的路径历史，例如前一条边、前若干条边、局部模式切换状态或累计转移信息等.

在路径依赖约束方面，交通网络中的转向惩罚、禁转规则以及节点过渡代价，是较早受到关注的典型问题.Winter 针对带转向限制的大规模道路网络，采用扩展标签的方式处理不可行转移，从而在一定程度上保留了最短路径求解框架\cite{winter2002labeling}.在随机与风险约束方面，Nikolova 等研究了带方差约束的最短路径问题\cite{nikoletta2010variance}，Sen 等则在路径引导场景中考虑了均值—方差模型\cite{sen2001mean}.近年来，Murphy 等以及后续研究进一步将条件加权图用于描述由前驱状态决定转移代价的路径规划问题\cite{murphy2018generalized}.此外，对于具有二次项耦合的最短路径问题，Rostami 等和 Hu 等分别从求解与线性化角度进行了研究\cite{rostami2015solving,hu2017polynomial}.总体来看，非加性最短路径问题的研究已从早期面向特定约束的局部处理，逐步发展到对更一般路径依赖型代价结构的刻画与求解.

不过，从已有研究看，对于具有有限阶历史依赖的路径代价结构，尤其是当前扩展代价依赖有限步局部历史的情形，现有方法虽然已经给出了标签扩展、状态展开与条件加权等处理思路，但在统一建模与高效求解之间仍存在明显张力.一方面，随着历史依赖阶数升高，路径状态空间会迅速膨胀；另一方面，如何在保持模型表达能力的同时兼顾计算效率，仍然是一个值得进一步研究的问题.本文正是在这一背景下，重点关注有限阶历史依赖下的路径依赖型非加性最短路径问题，其中“相邻边过渡代价依赖前驱边”是最常见也最具代表性的特例.

\subsection{线图理论及其在路径依赖问题中的应用}

线图是图论中的经典结构.Whitney 最早系统讨论了线图的同构性质与连通性问题\cite{whitney1932congruent}，Harary 等进一步研究了有向线图的结构性质\cite{harary1960some}，Melter 也对相关理论进行了补充\cite{melter1962interchange}.线图的基本思想是“化边为点”：将原图中的边映射为线图中的顶点，并将原图中可连续连接的边对映射为线图中的边.由于该变换能够显式表示“边与边之间的相邻关系”，因此其在处理边间耦合、转移约束以及高阶路径结构方面具有天然优势.

对于路径依赖型最短路径问题而言，线图方法的重要价值在于，它能够将原本隐含在路径历史中的局部状态关系，转化为图结构中的显式邻接关系.在线图框架下，原图中依赖相邻边关系的过渡代价可以通过线图边权进行编码，从而将原本难以直接处理的历史依赖约束转化为替代图上的静态边权问题.对于仅依赖前驱边的局部历史约束，线图提供了一种较为直接的状态展开方式；也就是说，一次线图转换即可将原图中的“边到边”过渡结构显式展开.已有研究表明，这种图变换思想能够为条件权重、转向惩罚以及局部历史依赖型路径规划问题提供较清晰的建模框架\cite{grandoni2008generalization,murphy2018generalized}.

进一步地，当当前扩展代价不只依赖前驱边，而是依赖此前有限条边所构成的局部历史时，线图思想仍可扩展适用.对于依赖更长有限历史的情形，可以通过构造高阶线图（或等价的多次线图转换），将有限长度的局部边序列压缩为新的状态节点，从而把原问题中有限阶的历史依赖结构映射为替代图上的局部静态关系.由此可见，线图不仅适用于相邻边过渡代价依赖前驱边的典型场景，也为更一般有限阶历史依赖问题提供了统一的结构化建模工具.

但需要指出的是，线图方法的优点与代价并存.线图转换虽然提高了模型表达能力，却也会带来图规模扩张.尤其在原图边数较大、局部连接较密，或者需要处理更高阶历史依赖时，替代图中的节点数与边数都可能迅速增加.也就是说，当历史依赖阶数较高时，高阶线图虽然在理论上能够提供统一建模方式，但与此同时也会显著抬高图构建与后续求解的计算成本.因此，如何在线图表示能力、问题统一性与计算复杂度之间取得平衡，已成为线图方法能否进一步落地应用的关键问题之一.

\subsection{基于 GPU 的大规模图算法并行研究}

随着图数据规模持续增长，传统 CPU 串行算法在大规模图计算中的效率瓶颈日益突出.特别是在最短路径、图遍历、图变换以及稀疏结构处理等任务中，随着节点数和边数增加，算法运行时间与内存访问开销往往快速增长.为提升此类任务的计算效率，研究者开始广泛采用 GPU 进行并行加速.

GPU 具有大规模线程并发执行和高内存带宽等优势，适合处理边级别或顶点级别相互独立的数据并行任务.在图算法领域，基于 CUDA 的并行实现已被应用于图遍历、稀疏矩阵计算、最短路径松弛以及图神经网络等多个方向.相比之下，传统 Dijkstra 算法由于依赖严格的全局优先队列，在并行环境中难以高效实现.为缓解这一问题，Meyer 和 Sanders 提出了 $\Delta$-Stepping 算法\footnote{MEYER U, SANDERS P. $\Delta$-stepping: a parallelizable shortest path algorithm[J]. Journal of Algorithms, 2003, 49(1): 114-152.}，通过桶结构代替严格排序的优先队列，在一定程度上兼顾了并行性与收敛效率.该算法允许将暂定距离处于同一区间内的多个顶点并发处理，因此更适合 GPU 架构下的批量松弛操作.

目前，GPU 图算法研究的重点主要集中在以下几个方面：一是如何设计适合并行硬件的图存储结构，以减少随机访存开销；二是如何缓解线程分支分歧和原子操作竞争带来的性能损失；三是如何针对具体算法中的关键参数进行调优，以提高设备利用率与整体吞吐能力.在求解阶段，批量松弛、波前扩展与桶式调度等操作往往具有较高的并行潜力，因此相关研究已较为丰富.

然而，与求解阶段相比，图结构转换阶段的并行研究仍相对不足.对于路径依赖型非加性最短路径问题而言，线图构建、条件权重计算以及桶式松弛过程都具有一定的数据并行潜力，但其中线图转换尤其值得关注.原因在于，线图转换不仅是建模步骤，也是高阶状态展开的主要来源.当原图规模较大或历史依赖阶数较高时，邻接关系生成、结构填充与权重映射的代价会显著增加，甚至可能成为整个求解流程中的主要瓶颈.尤其对于更一般的有限阶路径依赖情形，随着历史依赖阶数升高，替代图规模迅速膨胀，传统 CPU 串行构图方式很难保持可接受的效率.

因此，从本文所关注的问题出发，GPU 并行的意义不仅体现在最短路径求解阶段，更体现在高阶线图转换与替代图构建阶段.如何结合 CUDA 框架，在邻接展开、前缀和布局、CSR 填充以及条件加权等环节设计适合 GPU 的并行策略，从而缓解多阶线图转换带来的时间开销，是当前研究中仍有待进一步系统解决的问题.也正因为如此，将 GPU 并行与线图方法结合起来，不仅具有工程价值，也为该类路径依赖型问题的可扩展求解提供了现实基础.

\section{主要研究内容}

针对路径依赖型（有限阶历史依赖）非加性最短路径问题，本文围绕“线图建模—并行构建—并行求解”这一主线展开研究.其中，相邻边过渡代价依赖前驱边的问题是最常见的典型情形，而更一般的有限阶路径依赖问题则可通过高阶线图构造（或等价的多次线图转换）进行统一处理.本文的主要研究内容如下.

第一，建立面向路径依赖型非加性约束的线图建模框架.本文从原图到线图的映射关系出发，给出边到点、局部历史状态到替代节点、过渡关系到连边的形式化描述，并将原图中由相邻边或有限阶边序列过渡引起的非加性代价映射为替代图中的静态边权.在此基础上，构建面向路径依赖型非加性最短路径问题的条件权重最短路径（Conditional Weighting Shortest Path, CWSP）求解框架，并将其求解过程划分为三个阶段，即线图的拓扑替代构造、非加性约束的条件加权以及基于等效替代图的路径寻优.其中，对于仅依赖前驱边的典型情形，一次线图转换即可完成状态展开；对于更一般的有限阶路径依赖情形，则可通过高阶线图构造（或等价的多次线图转换）实现统一表达.

第二，设计基于线图的并行构建与条件加权实现方法.针对线图的拓扑替代构造过程中存在的邻接展开、内存分配与写入冲突等问题，本文采用基于前缀和的并行邻接生成策略，并结合 CSR 等稀疏存储格式实现连续内存布局.针对非加性约束的条件加权阶段中大量独立过渡代价评估任务，本文结合 GPU 的线程组织与访存特性，对边级并行计算过程进行优化，以提高吞吐率并降低条件权重计算阶段的时间开销.进一步地，考虑到随着历史依赖阶数升高，高阶线图规模会迅速膨胀，本文特别关注线图拓扑替代构造与条件加权两个阶段在不同历史阶数条件下的耗时变化，并分析其在高阶情形下逐渐成为主要性能瓶颈的规律.

第三，研究等效替代图上的并行路径寻优方法及其性能表现.考虑到传统 Dijkstra 算法不适合直接在 GPU 上高效实现，本文在替代图上采用更适合并行松弛的 $\Delta$-Stepping 算法\footnote{MEYER U, SANDERS P. $\Delta$-stepping: a parallelizable shortest path algorithm[J]. Journal of Algorithms, 2003, 49(1): 114-152.}，以桶式结构组织波前扩展过程，并通过原子更新实现线程安全的距离松弛.在此基础上，本文通过真实微观路网与不同规模的网络数据，对所提出方法的正确性与并行加速效果进行实验验证；同时，结合不同历史阶数条件下的线图转换与条件权重计算实验，进一步分析线图的拓扑替代构造、非加性约束的条件加权以及基于等效替代图的路径寻优三个阶段在不同历史阶数条件下的计算开销变化、GPU 加速比变化及整体性能表现，从而评估该方法向更复杂路径依赖场景扩展时的可行性与工程实用性.

概括而言，本文的工作旨在回答两个问题：其一，如何将有限阶历史依赖下的路径依赖型非加性最短路径问题转化为可计算的静态替代图模型；其二，如何在此基础上利用 GPU 并行能力提升线图的拓扑替代构造、非加性约束的条件加权以及基于等效替代图的路径寻优三个阶段的求解效率，尤其是在历史依赖阶数升高导致前两个阶段开销迅速上升的情况下，保持方法的可扩展性与计算效率.
\section{论文组织结构}

本文围绕路径依赖型（有限阶历史依赖）最短路径问题的建模、求解与并行化实现展开论述，全文结构安排如下：

\textbf{第一章 绪论：} 阐述研究背景与意义，给出问题定义与研究挑战，并概述本文的主要研究内容与技术路线.

\textbf{第二章 相关理论与问题建模：} 总结路径依赖型最短路径问题的建模特点与典型应用场景，说明传统加性最短路方法在历史依赖约束下的局限性，并引出线图映射与条件加权的基本思想.

\textbf{第三章 CWSP 框架与 GPU 并行化方法：} 系统介绍基于线图的 CWSP 三阶段流水线（拓扑替代构造、条件加权、替代图寻优），并针对 GPU 架构给出相应的并行实现与关键优化策略，包括前缀和驱动的 CSR 并发构建、边级条件权重计算优化以及桶式 $\Delta$-Stepping 算法并行寻优.

\textbf{第五章 总结与展望：} 总结全文工作与主要结论，归纳本文方法在建模统一性与并行可扩展性方面的贡献，并对高阶历史依赖场景下的结构压缩、并行寻优鲁棒性与工程落地等方向进行展望.

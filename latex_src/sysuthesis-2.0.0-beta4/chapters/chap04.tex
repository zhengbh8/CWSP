\chapter{数值实验与结果分析}

为了全面验证本文提出的基于线图映射的非加性最短路径算法（CWSP）的正确性以及面向 GPU 的并行优化方案的有效性，本章将开展多组定性与定量的对比实验。通过自建微观场景与真实大规模网络数据集，分别从算法的路径求解可行性和并行计算性能两个维度进行分析。

\section{实验环境与数据集}

\subsection{实验软硬件环境}
本章相关的串行与并行实验均在同一台计算节点上完成，以保证实验误差降至最低。硬件平台配置为：处理器方面，搭载了 \textbf{Intel(R) Xeon(R) CPU E5-2680 v4 @ 2.40GHz}（或其他对应的具体型号）；在并行加速方面，使用了 \textbf{NVIDIA RTX 4090 GPU}（24GB 显存，根据你的实际情况修改）。针对不同算法的具体实现，软件环境配置如下：
\begin{itemize}
    \item \textbf{操作系统}：Ubuntu 20.04 LTS (64-bit)。
    \item \textbf{开发语言与标准}：串行基准算法以及相应的预处理脚本基于 Python 3.10 及 NetworkX 库实现；GPU 并行算法基于 C++17 与 CUDA 12.1 框架编写。
    \item \textbf{编译环境}：使用 gcc/g++ 11.4 编译器以及 nvcc 编译器，并开起了 -O3 级别的深度优化。
\end{itemize}

\subsection{实验数据集说明}
为了客观地评估本文算法的计算性能，实验采用了两类数据集，详见以下说明：
\begin{itemize}
    \item \textbf{实体微观路网数据：} 取自迈阿密国际机场（MIA）的真实滑行道拓扑数据，包含数百个节点与物理交叉口。该路网用于验证算法能否在面临大夹角锐角转弯等非加性约束时，正确输出无碰撞的可行路径。
    \item \textbf{大规模网络数据集：} 为考察并行算法在图规模不断增加时的加速表现，实验引入或生成了多组处于不同数量级的大规模网络。图中顶点数记为 $n$，边数记为 $m$，通过赋予边与节点不同的权值和非加性转弯惩罚，用于极限压力测试。
\end{itemize}

\section{实验基准与评价指标}

\subsection{基准算法对比设置}
为了多维度衡量各类算法，实验选取了以下三组实现基准作为对照模型：
\begin{enumerate}
    \item \textbf{传统 Dijkstra 算法（基准线）：} 最早的未考虑非加性转弯惩罚的贪心最短路算法，作为考察由于未考虑约束导致其合法率下降的参照物。
    \item \textbf{串行线图 CWSP 算法（本文理论）：} 基于 Python 及纯 CPU 实现的线图转换与松弛算法。虽然兼顾了多约束惩罚，但在庞大节点数下可能存在极长的运行耗时，用以验证解的正确性。
    \item \textbf{基于 GPU 并行的 CWSP 算法（本文核心）：} 基于 CUDA 并行对线图转化与 Delta-Stepping 结构进行加速的优化实现，并在相同数据集上参与性能对比。
\end{enumerate}

\subsection{性能评价指标}
实验选用以下三个维度作为评价算法好坏的指标：
\begin{enumerate}
    \item \textbf{路径可行性（Success Rate）：} 代表算法求出的源节点至目标节点之间距离是否触发了非加性约束的高昂惩罚，若代价变为 $+\infty$ 则表示寻路失效，反之则成功。
    \item \textbf{运行时间（Running Time, 毫秒/秒）：} 在同等输入环境下算法求出结果的绝对计算耗时（为减少误差，实验结果均基于五次重复实验得出平均值）。
    \item \textbf{加速比（Speedup）：} 用于衡量并行优化带来的提升幅度，其计算公式为：$$ Speedup = \frac{T_{serial}}{T_{parallel}} $$ 其中 $T_{serial}$ 为对应的串行执行时间，$T_{parallel}$ 为 GPU 并行条件下的执行时间。
\end{enumerate}


\section{串行算法实验与可行性分析}

为了直观展示传统最短路径算法在非加性网络（如带转弯惩罚的路网）中的局限性，本节基于前期提取的迈阿密国际机场（MIA）滑行道真实拓扑，构造了极具代表性的微观局部陷阱，并利用随机抽取的大量长跨度点对进行了实验。

从图~\ref{fig:exp1_40cases} 和表~\ref{tab:exp1_40cases_full} 中的实验数据可以看出，在面临复杂非加性约束的情况下，线图 CWSP 算法对约束的处理效果相比传统算法有显著提升：
\begin{itemize}
    \item \textbf{传统算法对复杂约束适应性较差：} 面对具备较长跨度与多个交叉口的测试用例时，仅凭局部空间信息进行贪心寻路的传统 Dijkstra 算法难以规避连贯边产生的锐角惩罚。在 40 组测试案例中仅成功完成 20 组，有效寻路率仅有 50\%，这表明传统算法极易在深层约束路网中失效。
    \item \textbf{本文算法不仅合法且具有鲁棒性：} 无论随机抽取起点与终点的拓扑分布多么复杂，由于线图 CWSP 算法在预处理阶段通过变换网络结构实现了转弯特征向节点权重的内化，这使得其在面对惩罚机制时具有极强的预判和规避能力。最终该算法在 40 组测试中均得出了最优合法路径（成功率 100\%）。同时，在传统 Dijkstra 尚未失效的安全路段，二者的代价值完全相等，证明了本文算法未带来冗余的绕路偏差。
\end{itemize}

\section{本章小结}

本章主要使用微观机场路网与大规模通用网络数据集，对本文设计的基于线图的非加性最短路径算法及针对性 GPU 优化技术进行了实验对比。实验结果不仅从代价值正确性的维度证明了采用本架构能够对现实中由于急转弯造成的约束死锁进行 100\% 规避，并且通过对比并行加速率进一步验证了 GPU 并行松弛在大规模扩张的线图上拥有显著的时间效率收益，满足了高频并发的大型枢纽调度需求。

\chapter{数值实验和结果分析}

为了全面验证本文提出的基于线图映射的非加性最短路径算法（CWSP）的逻辑正确性，以及面向 GPU 架构的并行优化方案的加速效能，本章将开展多组定性与定量的对比实验。通过定制化微观路网场景与大规模模拟网络拓扑，分别从算法的求解可行性与超大规模并发吞吐两个维度进行深度剖析。

\subsection{实验数据集说明}
为了全面且客观地评估本文算法的适用性与扩展性，本章实验同时采用了以下两类数据集进行交叉验证：
\begin{itemize}

    \item \textbf{真实世界大规模路网数据集（Real-world Road Networks）：} 为了与顶尖文献\cite{durand2024generalized}中的压力测试条件对齐，并在绝对算力层级上激发 GPU 的并行潜能，本章引入了基于真实地理状态提取的大规模公开路网基准数据集（如源自 OpenStreetMap 提取的城市道路图或 第9届 DIMACS 最短路径挑战集提供的真实路网资料，规模从数万至数百万节点不等）。原图附带了真实路口的夹角转弯、通行级别等多元物理维度，能够充当最苛刻的非加性网络高频测试床。
\end{itemize}

\section{基于线图的串行算法与传统最短路径算法对比}

\subsection{路径可行性验证场景构造}
为了直观展示传统最短路径算法在非加性网络（如带转弯惩罚的路网）中的局限性，本节基于前期提取的迈阿密国际机场（MIA）滑行道真实拓扑，构造了极具代表性的微观局部陷阱。在航空地质调度中，飞机如果在高滑行速度下强行进行锐角转弯存在极大的事故风险。因此实验配置了严苛的转向约束条件：当两条相邻连通边构成的转弯夹角过大（如超过一定阈值构成了物理上的锐角转弯），将触发高达 $M=5000$ 米甚至正无穷大的硬性惩罚代价。

典型地，在迈阿密机场网络中，通过程序挖掘定位了起点节点 $v_s$（ID：2617）与终点节点 $v_d$（ID：2988）之间的一个死端约束枢纽 $v_m$（ID：1483）。在纯几何距离视角下，最短的连通方案为 $v_s \rightarrow v_m \rightarrow v_d$，其空间物理直线距离仅有 $48.43$ 米。然而，这一几何短路正是由两条近乎首尾折返的边相接而成，该走势在该路口构成了一个非法的“掉头式转角”。

\subsection{解空间与路径代价分析的宏观统计比对}
为确保实验的客观性与数据鲁棒性，并在统计意义上充分验证上述定性分析，本节在迈阿密国际机场全网中随机生成了 $40$ 组独立的测试点对。为了使得寻路任务具备足够的深度与空间跨度以暴露算法缺陷，在抽取数据时特意引入了拓扑结构上的限制：要求所有随机生成的起始节点 $v_s$ 与目标节点 $v_d$ 之间，其在地图网络上的最少跳数（Hop Distance）必须大于等于 $20$ 即跨越大量复杂的滑行道交叉口。

在此测试集上，分别运行受限条件（带转弯惩罚）下的传统 Dijkstra 算法与本文基于线图模型的 CWSP 算法。两种算法在 40 组独立实验中的表现状态与求得的最优合法（无违规急转弯）几何距离代价统计情况如图~\ref{fig:exp1_40cases} 所示。该图不仅直观反映了算法在各项寻路任务中的代价值差异，更揭示了传统算法因缺乏前瞻性约束建模而陷入停滞或违规死锁的失败比例。

结合表~\ref{tab:exp1_40cases_full} 的全部明细记录以及图~\ref{fig:exp1_40cases} 的宏观定性分析，可归纳出引入线图拓扑转换求解非加性路径约束的必要性与优越性，具体体现为以下三个方面：
\begin{enumerate}
    \item \textbf{长距复杂约束下传统算法极易失效：} 在跨越距离长、交叉口密集的复杂路由任务（$\ge 20$ 跳）中，由于缺乏对连续边约束的预判与规避能力，传统 Dijkstra 算法容易陷入局部最优陷阱，最终生成含有违规转弯的不可行路径（如图~\ref{fig:exp1_40cases} 中红色标记所示）。由统计结果可知，传统算法在 40 组样本中仅有 50\%（20 组）未触发障碍，其余均遭遇约束壁垒导致代价发散。这表明经典基于点松弛的标量加权法难以应对多约束的物理网络拓扑。
    \item \textbf{无约束路段下的最优性与兼容性：} 对于未触发锐角转向等严苛约束的常规路线（例如表中的第 4 或第 6 组测试），线图 CWSP 算法给出的最短路径代价值与传统策略完全一致，代价曲线高度重合。这一对照说明，复杂的线图映射过程并未对常规路段的寻路造成冗余绕路或其他负面影响，算法能够向下兼容传统的加性最短路径问题，体现出良好的鲁棒性。
    \item \textbf{线图模型确保全局路径严格合法与最优：} 无论随机抽取起点与终点的拓扑分布多为复杂，线图 CWSP 算法均可通过新网络 $L(G)$ 的转移特性，在预处理阶段将二元非加性惩罚静态内化为节点的固有属性。这赋予了算法全局的风险洞察力，能够在面对恶劣转弯时准确实施代价最小的迂回策略。最终，该算法取得了 100\% 的有效寻路成功率，严谨地求得了既满足数学最优化，又兼顾物理空间通畅性的合法最短路径。
\end{enumerate}

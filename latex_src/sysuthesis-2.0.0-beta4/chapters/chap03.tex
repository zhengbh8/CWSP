\section{线图转换对非加性问题的适配性分析}

正如第二章所述，现实网络中常见交规转弯惩罚、能耗随路径状态变化等路径依赖现象，使得“路径代价可加”的经典最短路径建模在部分场景下不再直接适用.在这类非加性（Non-additive）最短路径问题（亦可视为条件权重最短路径问题）中，边的通行代价不再仅由该边自身决定，而可能受到前驱历史状态的影响.为刻画此类具有有限历史依赖的代价函数，相关研究提出了有限图的差分分析（Differential Analysis on Finite Graphs）框架，将路径上的代价增量表示为差分算子 $\partial f(\alpha | p)$ 的叠加形式\cite{durand2024generalized}.

依据该表示形式，路径代价可以写成沿路径的局部差分增量之和：
\begin{equation}
    f(p) = \sum_{\alpha \in p} \partial f(\alpha | p)
\end{equation}
其中，$P$ 表示图 $G$ 中所有合法路径的集合，$p \in P$ 为某一条具体路径；$\alpha \in E_G$ 表示构成该路径的某一条有向边；算子 $\partial f(\alpha | p)$ 定义为在给定前置历史路径段的情况下，拓展边 $\alpha$ 接入该路径所带来的局部代价增量（即，$\partial f(\alpha|p) = f(p \cup \{\alpha\}) - f(p)$）.

在此基础上，若到达某条目标边 $\alpha$ 的差分代价变动 $\partial f$ 仅受其紧邻的前面 $k$ 条边（即有限深度历史）的条件影响，则该代价函数被称为 \textbf{$k$-加性（$k$-additive）函数}，记作 $f \in F^{(k)}_G$.在该定义下，传统可加性最短路径对应 0-加性函数（$F^{(0)}_G$）；而包含转弯惩罚或局部前驱约束的模型，在一定假设下可归入 1-加性或 2-加性等有限阶情形.

针对这类有限阶历史依赖的 $k$-加性问题，\textbf{线图（Line Graph）转换}提供了一种直接的状态展开方式：
\begin{itemize}
    \item \textbf{状态显式化：} 对于 1-加性代价的原图 $G(V_G, E_G)$，路径扩展的代价依赖于“上一条边”.通过将原图有向边映射为线图 $L(G)$ 的节点（$V_{L(G)} = E_G$），可将原问题中隐含的“边到边”的状态过渡显式表示为图上的节点转移.
    \item \textbf{代价静态化：} 在原图 $G$ 中由历史条件诱导的转移代价（例如 $\partial f(\beta | \alpha)$），可在线图 $L(G)$ 中作为相邻节点对之间的静态边权进行编码，从而得到可用加性最短路径算法处理的替代问题.
\end{itemize}

综上，通过线图转换可以将原网络上具有有限历史依赖的 $k$-加性寻路问题，转换为替代图 $L(G)$ 上的加性最短路径问题，从而便于调用现有最短路径求解流程.基于该思路，Durand 等人\cite{durand2024generalized}提出了条件权重最短路径（Conditional Weighting Shortest Path, CWSP）算法框架.下文将对该算法的设计与等价性说明进行阐述，并为后续并行化实现讨论作准备.

\section{基于线图的算法设计}

基于上述表示与线图转换思路，现有研究提出了条件权重最短路径（CWSP）算法框架\cite{durand2024generalized}，用于求解包含有限阶前驱依赖的最短路径问题.CWSP 的三阶段处理链路如图~\ref{fig:cwsp_pipeline}所示，分别对应线图拓扑替代构造、条件加权计算与替代图最短路径寻优.本节按这三个步骤介绍其基本流程.

\subsection{第一阶段：线图的拓扑替代构造}
算法的第一步是将原图 $G=(V_G, E_G)$ 中“边与边的可连接关系”显式化为替代图的邻接关系.该过程给出原图到替代图（Alternative Graph，即线图 $H = L(G)$）的映射规则：
\begin{enumerate}
    \item \textbf{节点生成：} 为原图 $G$ 中的每一条有向边 $\alpha \in E_G$ 在新图 $H$ 中创建一个对应的单一实体节点.即新图节点集由原图边集构成：$V_H = \{ u \mid u = \alpha \in E_G \}$.
    \item \textbf{连边构建：} 若在原图 $G$ 中边 $\alpha$ 与有向边 $\beta$ 可连接（即边 $\alpha$ 的终点与边 $\beta$ 的起点为同一节点），则在线图 $H$ 中创建一条连接前驱节点与后续节点的新边，即 $E_H = \{ (\alpha, \beta) \mid \alpha, \beta \in V_H, \text{且~} \alpha_2 = \beta_1 \}$.
\end{enumerate}

综上拓扑映射规则，该阶段具体的构造过程如算法 \ref{alg:line_graph} 所示.

\begin{algorithm}[H]
\caption{线图的拓扑替代构造}\label{alg:line_graph}
\KwIn{原图 $G = (V_G, E_G)$}
\KwOut{线图 $L(G)$}
$V_{L(G)} \leftarrow \{(\alpha) \mid \alpha \in E_G\}$\;
$E_{L(G)} \leftarrow \emptyset$\;
\ForEach{$\alpha \in E_G$}{
    \ForEach{$\beta \in E_G$}{
        \If{$\alpha_2 = \beta_1$}{
            $E_{L(G)} \leftarrow E_{L(G)} \cup \{(\alpha, \beta)\}$\;
        }
    }
}
$L(G) \leftarrow (V_{L(G)}, E_{L(G)})$\;
\Return $L(G)$\;
\end{algorithm}

如算法 \ref{alg:line_graph} 所示，该生成过程通过遍历原图边集合 $E_G$ 生成线图的节点集与边集.第 4--5 行初始化 $L(G)$ 的节点集和边集；第 6--12 行枚举原图有向边对 $(\alpha, \beta)$，判断是否满足连接条件 $\alpha_2=\beta_1$，从而决定是否在 $L(G)$ 中添加有向边 $(\alpha,\beta)$.该过程给出线图的拓扑结构.

\subsection{第二阶段：非加性约束的条件加权}
替代图 $H$ 生成后，需要将历史依赖代价映射到替代图边集合 $E_H$ 上.假定问题的代价函数最多取决于 $k$ 级历史状态，则对替代图上的每条转移边 $(\alpha, \beta)$，可依据差分算子给出其对应的静态权重：
\begin{equation}
    W_H(\alpha \to \beta) = \partial f(\beta \mid \alpha)
\end{equation}
在上述定义下，历史依赖项通过局部差分写入替代图的边权，从而将原问题转化为替代图上的加性最短路径形式.该阶段权重映射逻辑如算法 \ref{alg:conditional_weight} 所示.

\begin{algorithm}[H]
\caption{替代图的条件加权}\label{alg:conditional_weight}
\KwIn{原图 $G = (V_G, E_G)$，复杂代价函数 $f$，代价函数的加性阶数 $k$}
\KwOut{带权替代图 $H = (V_H, E_H, W_H)$，其中 $H$ 本质为高阶线图 $L^{[k]}(G)$}
$H \leftarrow L^{[k]}(G) $ \tcc*{利用算法 \ref{alg:line_graph} 构造高阶线图}
\ForEach{$(u_H, v_H) \in E_H$}{
    $(u_1, \dots, u_{k+1}) \leftarrow u_H$\tcc*{其中 $l(u_H)=l(v_H)=k+1$}
    $(v_1, \dots, v_{k+1}) \leftarrow v_H$\;
    $\beta \leftarrow (u_{k+1}, v_{k+1})$ \tcc*{提取最新扩展边 $\beta \in E_G$}
    $w_{(u_H, v_H)} \leftarrow \partial f(\beta \mid u_H)$ \tcc*{计算差分并赋静态权重}
}
$V_H \leftarrow V_H \cup V_G$\;
\ForEach{$u_H \in V_H$}{
    $u \leftarrow (u_H)_1$\;
    $\gamma \leftarrow (u, u_H)$ \tcc*{从原图节点进入替代图 $H$ 的连边}
    $E_H \leftarrow E_H \cup \{\gamma\}$\;
    $w_\gamma \leftarrow f((u_H)_1, \dots, (u_H)_k)$\;
}
$W_H \leftarrow \{w_e \mid e \in E_H\}$\;
\Return $H = (V_H, E_H, W_H)$\;
\end{algorithm}

算法 \ref{alg:conditional_weight} 给出了将历史依赖代价写入替代图边权的计算过程.第 1 行构造高阶线图结构；第 2--6 行遍历替代图边 $(u_H,v_H)$，提取最新扩展边 $\beta$ 并计算 $\partial f(\beta\mid u_H)$ 作为静态权重.第 8--13 行为从原图节点进入替代图的连接边赋予边界代价，用于处理起始状态的初始化.

\subsection{第三阶段：基于等效替代图的路径寻优}
完成拓扑替代与权重映射后，替代图 $H$ 可作为加性有向图处理，从而可以在其上运行 Dijkstra 等最短路径算法.由于替代图节点对应原图边（或状态），在实现时需要相应调整终止条件与路径回溯方式.

在原始最短路径问题中，寻路过程当目标节点 $t \in V_G$ 被从优先队列弹出时即告结束.但在替代图 $H$ 结构下，节点实质为原图空间中的一条“转移线段”.因此，Dijkstra 算法的停止条件转变为：当优先队列弹出的当前节点（即某条有向边）的终点，恰好指向原问题的全局目标节点 $t$ 时，寻路探索即告完成.随后，运用回溯法依据前驱指针（predecessor）即可输出映射回原图的完整最小代价通路 $p^*$.针对转换后图结构的单源最短路寻优完整步骤如算法 \ref{alg:dijkstra_sub} 所示.

\begin{algorithm}[H]
\caption{基于替代图的 Dijkstra 寻路算法}\label{alg:dijkstra_sub}
\KwIn{带权替代图 $H = (V_H, E_H, W_H)$，起点 $s$，终点 $t$}
\KwOut{最优路径 $p^*$}
\ForEach{$v_H \in V_H$}{
    $\text{cost}[v_H] \leftarrow \infty$\;
    $\text{predecessor}[v_H] \leftarrow \emptyset$\;
}
\tcc{此处省略了与起点相关的初始化细节，默认包含从起点关联起步的过程}
$\text{cost}[s'] \leftarrow 0$ \tcc*{$s'$表征线图层级下对应源节点的特定起始状态}
$Q \leftarrow V_H$\;
\While{$Q \neq \emptyset$}{
    $u_H \leftarrow \text{extract-min}(Q)$\;
    \ForEach{连边 $\alpha_H = (u_H, v_H) \in E_H$}{
        \If{$\text{cost}[v_H] > \text{cost}[u_H] + w_{\alpha_H}$}{
            $\text{cost}[v_H] \leftarrow \text{cost}[u_H] + w_{\alpha_H}$\;
            $\text{predecessor}[v_H] \leftarrow u_H$\;
        }
        \If{$(v_H)_{k+1} = t$}{
            $u_{\text{last}} \leftarrow v_H$\;
            \textbf{break}\;
        }
    }
}
$p^* \leftarrow (t)$\;
$u_H \leftarrow u_{\text{last}}$\;
\While{$l(u_H) = k+1$}{
    $v_H \leftarrow u_H$\;
    $u_H \leftarrow \text{predecessor}[v_H]$\;
    $p^* \leftarrow ((u_H)_{k+1}, p^*)$\;
}
$p^* \leftarrow ((v_H)_1, \dots, (v_H)_k, p^*)$\;
\Return $p^*$\;
\end{algorithm}

结合算法 \ref{alg:dijkstra_sub} 可知，其前 14 行与标准 Dijkstra 的基本框架一致.差异主要体现在终止条件：在替代图 $H$ 中，节点对应原图中的边（或状态），因此当当前弹出的状态其末端节点达到目标节点 $t$ 时即可终止.随后通过前驱指针回溯，将替代图上的状态序列映射回原图上的边序列，从而得到最优路径.

\subsection{算法理论最优性的论证}
为说明上述转换与求解过程的正确性，下面给出其与原图非加性问题最优解之间的等价性说明.

\textbf{定理 3.1（最优性等价定理）} \textit{设给定有向图 $G(V_G,E_G)$ 及由源点 $s$ 至终点 $t$ 的 $1$-加性路径寻优问题，目标函数为 $\min_{p \in P_G(s,t)} f(p)$.设 $H(V_H,E_H,W_H)$ 为依据上述 CWSP 算法第一、二阶段条件加权构造出的线图，则在该图中依据第三阶段求得的纯加性最短路径解集 $\arg\min_{q \in P_H} \sum_{e \in q} W_H(e)$，其必然映射回 $P_G(s,t)$ 并对应 $f(p)$ 的全局最优解.}

\textbf{证明:}

\textbf{步骤一：解空间的双射映射性质（Bijective Mapping of Solution Space）}  
设 $p^* \in P_G(s,t)$ 为原图中的一条有效路径边序列，记为 $p^* = \langle \alpha_1, \alpha_2, \dots, \alpha_n \rangle$，起点判定条件为 $(\alpha_1)_1 = s$，终点为 $(\alpha_n)_2 = t$.依据 CWSP 第一阶段生成规则 $V_H = E_G$ 且 $E_H = \{ (\alpha_i, \alpha_{i+1}) \}$，该序列 $p^*$ 的邻接特征在 $H$ 中唯一显化为一条有效节点路径 $q = \langle v_1, v_2, \dots, v_n \rangle \in P_H$，满足 $v_i = \alpha_i \in V_H$.这也论证了 $P_G$ 与 $P_H$ 解空间之间存在严格的一一双向映射算子 $\Phi : p^* \mapsto q$.

\textbf{步骤二：非加性向加性的代价等价性（Cost Equivalence）}  
基于代价函数的差分分解定义与 $1$-加性截断边界属性，原图中路径 $p^*$ 的组合代价可递推展开：
\begin{align}
    f(p^*) &= f(\langle \alpha_1, \alpha_2, \dots, \alpha_n \rangle) \notag \\
           &= f(\alpha_1) + \sum_{i=1}^{n-1} \partial f(\alpha_{i+1} \mid \langle \alpha_1, \dots, \alpha_i \rangle) \notag \\
           &= f(\alpha_1) + \sum_{i=1}^{n-1} \partial f(\alpha_{i+1} \mid \alpha_i)
\end{align}
而对应由 CWSP 第二阶段权值定义的映射线图路径 $q$ ，其 $0$-加性累积模型为：
\begin{equation}
    W_H(q) = w_{enter}(\alpha_1) + \sum_{i=1}^{n-1} W_H(v_i, v_{i+1})
\end{equation}
定义起始惩罚 $w_{enter}(\alpha_1) = f(\alpha_1)$ 及连边静态权值项 $W_H(v_i, v_{i+1}) = \partial f(\alpha_{i+1} \mid \alpha_i)$ 后，上述两式可建立如下等价关系：$\forall p^* \in P_G(s,t), \, f(p^*) \equiv W_H(\Phi(p^*))$.

\textbf{步骤三：最优解一致性（Optimality Convergence）}  
设经由 CWSP 第三阶段寻路，在 $H$ 平面上求得 $\min_{q \in P_H} W_H(q)$ 对应的最短线路 $q^*$.假定在原图 $G$ 中存在一条总代价更小的有效路径 $p'$ 满足 $f(p') < f(\Phi^{-1}(q^*))$；由于定理证明的映射等价性 $f(p^*) \equiv W_H(q^*)$ 约束，必然在线图 $H$ 中也存在一条对应的有效同构轨迹 $q' = \Phi(p')$，满足 $W_H(q') < W_H(q^*)$.这与“$q^*$ 是 $H$ 中的最小权重路径”这一前提假设相矛盾.
因此，假设不成立，$f(\Phi^{-1}(q^*))$ 必然是全局绝对下确界.这表明了 CWSP 算法解得的 $q^*$ 完全等价于原问题网络的最优解.定理论证闭环，证毕.

需要指出的是，通过状态展开构造线图会带来规模增长：例如对 $m$ 阶线图有 $|E_{L^m(G)}| \leq n^{m+2}$（$n$ 为节点数）.当图规模较大时，构图、赋权与最短路径求解的开销可能成为瓶颈.针对此类计算需求，可考虑基于 GPU 的并行实现以提升吞吐.


\section{算法的并行优化}

针对 CWSP 在线图转换与求解过程中可能出现的规模扩张与计算开销，本节基于 GPU 的 CUDA 并行架构，讨论三个阶段的并行实现要点：线图拓扑结构构建、条件权重计算，以及采用更适合并行的最短路径算法替代基于优先队列的串行实现.

\subsection{线图拓扑结构的并行构建}

在线图生成阶段，原图 $G$ 中边的相邻关系判定在数据层面相对独立，适合采用数据并行方式实现.

在并行实现中，为适配 GPU 的内存访问与并发写入特性，通常避免依赖链式结构的动态分配.本文采用\textbf{压缩稀疏行（Compressed Sparse Row, CSR）}格式将图结构存储于设备全局内存（Global Memory）中，并采用以“边”为粒度的两阶段并行映射策略.

第一阶段为\textbf{度数统计与空间预分配}.由于原图中不同边对应的后继边数量不同，为减少并发写入冲突，可先以线程为单位统计每条原图边 $\alpha$ 的合法后继边数量，得到线图出度数组；再通过并行前缀和（Exclusive Prefix Sum / Scan）计算写入偏移，确定线图总边数并完成连续空间分配.前缀和结果同时为每条边提供了在目标数组中的写入起始位置（offset）.

第二阶段为\textbf{拓扑实例化写入}.在第二次核函数（Kernel）调用中，各线程根据第一阶段得到的偏移量，将合法的 $(\alpha, \beta_i)$ 转移关系写入 CSR 结构的预分配区间.该模式避免了对同一写入位置的竞争，从而减少对显式互斥机制的依赖，并降低等待开销.

\subsection{条件权重的并行计算}

线图结构构建完成后，转移边及其映射信息可存储为连续数组.此时，为线图赋权的差分代价计算可按边并行执行，属于典型的单指令多数据（SIMT）工作负载.

在该步骤中，可对替代图边集合 $E_H$ 启动一维核函数：每个线程依据全域线程索引映射到一条转移边 $e_H=(\alpha,\beta)$，读取所需的几何或历史状态相关属性，计算对应的差分代价，并写入权值数组.

该阶段的实现通常关注两点：其一是\textbf{合并内存访问（Memory Coalescing）}，即将边与属性以连续数组组织，提高相邻线程读写的空间局部性，从而提升带宽利用率；其二是\textbf{降低线程束分歧（Warp Divergence）}，即尽量减少复杂分支对同一 warp 内线程执行路径一致性的影响.上述策略有助于提升整体吞吐，但实际收益也受代价计算函数复杂度与数据分布影响.

\subsection{GPU友好的并行寻优算法替代}

在完成线图构建与赋权后，需要在替代图上求解单源最短路径.传统 Dijkstra 算法依赖严格的全局优先队列（Priority Queue）与逐步选取最小距离顶点的过程，具有较强的顺序依赖，因此在 GPU 上实现高效并行通常较为困难.

为提高并行度，本文采用更适合批量松弛的 $\Delta$-Stepping 算法替代基于优先队列的实现.该算法通过将距离划分为区间桶，在保证正确性的前提下允许桶内并行松弛.其面向 GPU 的实现要点如下：
\begin{enumerate}
    \item \textbf{桶结构与并行松弛：} $\Delta$-Stepping 算法使用桶（Bucket）数组替代严格排序的优先队列.给定步长参数 $\Delta$，将距离落在区间 $[i\Delta, (i+1)\Delta)$ 的节点归入桶 $B_i$，并对桶内节点的松弛操作并行执行.在实现中，可将当前桶的活跃节点集合缓存在线程块的\textbf{共享内存（Shared Memory）}中，以降低访问延迟.
    \item \textbf{并发更新与原子操作：} 桶内并行松弛可能导致多个线程同时尝试更新同一节点距离.为保证结果一致性，可使用原子最小更新（Atomic Minimum），例如 \texttt{atomicMin}，以在并发条件下安全地写回最小距离值.
    \item \textbf{同步与迭代推进：} 由于桶处理存在阶段性依赖，通常需要在每轮桶处理结束后设置同步点（例如以 kernel 边界或设备同步实现），以确保下一轮迭代在一致的距离状态上进行.
\end{enumerate}

综上，通过在线图上采用 $\Delta$-Stepping 算法可减少对严格优先队列次序的依赖，从而更容易在 GPU 上实现并行松弛.其性能收益与图结构、参数 $\Delta$ 以及实现细节相关，后续实验章节将对相关影响因素进行分析.

\section{算法复杂度与空间开销分析}

为便于评估 CWSP 在不同规模数据上的适用性，有必要从图规模增长、三阶段求解复杂度以及 GPU 显存占用三个层面进行统一分析.以下讨论以原图 $G(V_G,E_G)$、一次线图替代图 $H=L(G)$ 以及高阶替代图 $H^{(k)}=L^{[k]}(G)$ 为对象，并结合第4章中的规模扩展实验进行解释.

\subsection{线图规模增长分析}

对于一次线图 $H=L(G)$，其节点集与原图边集一一对应，因此有
\begin{equation}
    |V_H| = |E_G|.
\end{equation}
而线图中的一条边对应原图中两条首尾相接的有向边对.设原图中顶点 $v$ 的入度与出度分别为 $d_{in}(v)$ 与 $d_{out}(v)$，则一次线图的边数可写为
\begin{equation}
    |E_H| = \sum_{v \in V_G} d_{in}(v)\, d_{out}(v).
\end{equation}
由此可见，线图规模并不只受原图边数控制，还与中间顶点处的入出度耦合程度密切相关.若记原图最大出度为 $\Delta_{out}$、最大入度为 $\Delta_{in}$，则有
\begin{equation}
    |E_H| \le |V_G|\,\Delta_{in}\,\Delta_{out},
\end{equation}
从而一次线图的规模增长通常快于原图本身.对于有限阶历史依赖情形，若定义第 $k$ 阶替代图为 $H^{(k)}=L^{[k]}(G)$，则其状态空间会随着历史长度递增而快速扩张.以平均分支因子 $\bar d$ 进行粗略刻画时，可将规模上界写成
\begin{equation}
    |V_{H^{(k)}}| = O\bigl(|E_G|\,\bar d^{k-1}\bigr), \qquad |E_{H^{(k)}}| = O\bigl(|E_G|\,\bar d^{k}\bigr).
\end{equation}
若进一步采用最坏情况估计，则也可将其理解为随 $k$ 增大而呈指数式膨胀的上界.这一结论与第4章中 $k$ 从 1 增至 5 时替代图节点数、边数同步快速增长的现象一致，而在 $k=6$ 时出现显存不足，则正是该规模膨胀的直接后果.

\subsection{CWSP 三阶段时间复杂度分析}

\textbf{阶段1：线图拓扑构建.} 若采用直接枚举相邻边对的方式，线图的构建工作量与 $\sum_{v\in V_G} d_{in}(v)d_{out}(v)$ 同阶；在最坏情况下，可写作 $O(|E_G|^2)$.但在本文面向 GPU 的实现中，阶段1实际采用“度数统计 + 并行前缀和 + CSR 写入”的方式，其核心开销由一次度数扫描、一次前缀和以及一次按偏移写入组成，因此总体工作量可概括为 $O(|V_G|+|E_G|+|E_H|)$.其中，前缀和部分的并行深度通常为 $O(\log |V_G|)$，更适合大规模数据的批量处理.

\textbf{阶段2：条件权重计算.} 阶段2对替代图中的每条边独立计算差分代价，计算过程不依赖全局顺序，因此其工作量与替代图边数线性相关，可记为
\begin{equation}
    T_2 = O(|E_H|).
\end{equation}
若将边权计算进一步拆分为几何量读取、夹角判断与条件惩罚赋值，则单边代价仍为常数级，故整体复杂度主要由边数决定.该性质也解释了为什么第4章中随着线图规模增大，阶段2耗时会随 $|E_H|$ 近似同步上升.

\textbf{阶段3：替代图最短路径寻优.} 在不考虑并行化加速时，若阶段3采用带优先队列的 Dijkstra 算法，则其时间复杂度为
\begin{equation}
    T_3 = O\bigl((|V_H|+|E_H|)\log |V_H|\bigr).
\end{equation}
若采用本文所讨论的桶式 $\Delta$-Stepping 并行实现，则在理想并行条件下，其工作量仍与图规模线性同阶，可近似写为
\begin{equation}
    T_3 = O\bigl(|V_H|+|E_H|+L/\Delta\bigr),
\end{equation}
其中 $L$ 为最短路径的有效距离范围，$\Delta$ 为桶宽参数.由此可见，阶段3在算法层面仍受图规模支配，而并行化主要降低的是关键路径长度与常数因子.结合第4章实验可以看出，当图规模与历史阶数同时增大时，阶段3的并行收益通常更加明显，但其绝对耗时仍会随 $|V_H|$ 与 $|E_H|$ 的增长而上升.

\subsection{GPU 显存开销分析}

CWSP 在 GPU 上运行时，显存开销主要来自替代图结构本身、最短路径求解所需的辅助数组，以及构建阶段的临时缓冲区.若采用 CSR 表示替代图，则静态图结构的主要存储项包括：
\begin{equation}
\begin{aligned}
    M_{CSR} ={}& (|V_H|+1)\cdot \text{sizeof}(\texttt{row\_ptr}) \\
    &+ |E_H|\cdot \text{sizeof}(\texttt{col\_indices}) \\
    &+ |E_H|\cdot \text{sizeof}(\texttt{weights}).
\end{aligned}
\end{equation}
此外，在寻优阶段还需要保存距离数组 dist、前驱数组 predecessor、桶或 frontier 结构，以及用于并行扫描和写回的临时缓冲区，其开销可概括为
\begin{equation}
\begin{aligned}
    M_{aux} ={}& |V_H|\cdot \text{sizeof}(\texttt{dist}) + |V_H|\cdot \text{sizeof}(\texttt{predecessor}) \\
    &+ M_{bucket/frontier} + M_{scan\ buffer} + M_{state\ mapping}.
\end{aligned}
\end{equation}
其中，$M_{bucket/frontier}$ 通常与活跃顶点规模同阶，$M_{scan\ buffer}$ 用于前缀和与中间计数，$M_{state\ mapping}$ 则用于记录原图边、状态与替代图节点之间的映射关系.故整个 GPU 侧峰值显存可近似写为
\begin{equation}
    M_{GPU} = O(|V_H|+|E_H|+B+S),
\end{equation}
其中 $B$ 表示桶/前沿相关缓冲规模，$S$ 表示状态映射与扫描缓冲规模.

当历史阶数 $k$ 增大时，$|V_{H^{(k)}}|$ 与 $|E_{H^{(k)}}|$ 会按近似指数规律扩张，导致 CSR 三元组、距离数组、前驱数组与临时缓冲区同步放大.由于这些数组几乎都需要按替代图规模线性分配，故总显存开销会迅速逼近甚至超过单卡容量上限，这也是第4章中 $k=6$ 时出现 out-of-memory 的根本原因.换言之，显存瓶颈并非仅由某一个数组触发，而是由“替代图规模膨胀 + 多类线性辅助数组叠加”共同造成的峰值压力.

综上，CWSP 的复杂度瓶颈主要来自高阶历史依赖引起的替代图爆炸式增长；而 GPU 并行化的优势，则主要体现在把阶段1与阶段2中的独立计算以及阶段3中的桶内松弛尽可能并行展开，从而在可接受的显存预算下提升总体吞吐.

\section{本章小结}

本章围绕非加性最短路径问题的建模与求解流程，讨论了线图转换及其并行实现的基本思路.

首先，本章基于有限图差分分析与 $k$-加性函数的定义，说明了线图转换在刻画有限阶历史依赖代价方面的作用.通过将原图中的边到边转移显式化，并将历史依赖代价编码为替代图中的静态边权，可将原问题转化为替代图上的加性最短路径求解，并给出了相应的等价性证明.

其次，针对线图转换可能带来的规模增长，本章讨论了面向 GPU 的并行实现要点：在拓扑构建阶段使用前缀和与 CSR 进行空间分配与写入组织；在条件加权阶段按边并行计算权重；在最短路径阶段采用 $\Delta$-Stepping 算法等更适合并行松弛的算法替代串行优先队列流程.上述内容为后续实验评估提供实现层面的说明.
